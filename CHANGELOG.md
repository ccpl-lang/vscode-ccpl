# Changelog

All notable changes to the CCPL VS Code extension are documented here.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-09-21

### Added

- Repository metadata, MIT license, icon and gallery banner.
- Highlighting for native parameter and return type annotations (`func f(a: i32): i32`).

### Changed

- Synced grammar with the current compiler keyword and builtin set.

## [0.1.0] - 2026-09-01

### Added

- Initial release: syntax highlighting, bracket matching and comment support for `.ccpl` files.
